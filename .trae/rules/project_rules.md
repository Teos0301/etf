# 项目规则（ETH 永续合约行情分析）

本文件随仓库走，新工作区克隆后自动生效，用于替代"只存在于旧会话里的约定"。

## 1. 项目定位

直连交易所 API 抓 ETH/USDT 永续合约多周期 K 线，计算指标与形态，产出**自包含 HTML 报告**（数据内联，双击即看，不依赖外部资源）。

## 2. 数据源铁律

- **绝不使用网页缓存快照、历史结论、记忆里的旧价格**。每次回答行情问题都必须重新执行脚本。
- 优先 Gate 永续（`api.gateio.ws`）；OKX、binance fapi 在部分网络下会超时，属于已知现象，脚本已内置降级。
- 报数时必须标注数据源与抓取时间；抓不到就如实说"未取到"，**禁止编造价格**。

## 3. 脚本链路（全部在 `scripts/`，纯相对路径，任意机器可跑）

| 脚本 | 作用 |
|---|---|
| `check_prices.py` | 轻量：ETH/ZEC 现价 + 24h 高低 + 最近 24 根 1h |
| `eth_timeline.py` | 4h/1h 时间线，看结构与关键位 |
| `fetch_all.py` | 全量刷新 `klines.json`（多交易所降级） |
| `compute.py` | 指标/形态/策略引擎，产出 `summary.json` |
| `build_html.py` | 组装报告 → 仓库根目录 `ETH永续合约_多周期K线分析.html` |

标准流程：

```bash
python scripts/check_prices.py        # 每次必跑
python scripts/eth_timeline.py        # 每次必跑
# 行情变化大 或 需要出报告时：
python scripts/fetch_all.py && python scripts/compute.py && python scripts/build_html.py
```

依赖：`pip install requests`。脚本会自行 chdir 到自己所在目录，无需关心当前路径。

## 4. 账户与风控（硬约束，不得放宽）

- 本金 **100 U**，**5 倍逐仓**。
- 单笔风险敞口 ≤ **3 U**（按止损距离反推仓位，不许超）。
- 单日累计亏损达 **5 U** 立即停手，当日不再开新仓。
- 实际下单量只允许 **0.05–0.1 ETH**，超出即违规。
- **ZEC 永不下单**，即使被问到也只做行情陈述、不给交易方案。

## 5. 输出结构（行情类回答固定顺序）

1. 数据源与抓取时间
2. 行情快照表（价格、24h 高低、涨跌幅、资金费率）
3. 发生了什么 + 结构判读（多周期共振/关键位/形态）
4. 策略表（方向、入场区、止损、止盈、建议仓位、失效条件）
5. 执行要点（分批、不追单、无效即放弃）
6. ZEC 段落（只报行情，不下结论）
7. 一句话总结
